Parametriska filter — ställ in för hand

Går inte via MIDI. Ladda REW-JSON ovan så fylls tabellen. Stereolink påverkar inte PEQ → ställ in på både L och R.

#FrekvensGainQ≈ bandbredd
ingen JSON laddad

På DSP8000: PEQ-sidan → välj filter 1/2/3 → sätt frekvens, bandbredd (oktav) och gain (0,5 dB-steg, +16…−48 dB). De 3 filtren delas med Feedback Destroyer. Spara som program när klart.

Går inte via MIDI heller: delay, gate, limiter, feedback destroyer, Auto-Q, stereolink. Ställ på enheten, spara program, hämta via programval.
Verifiera alltid med en REW-sweep – enheten rapporterar inte tillbaka sitt tillstånd på ett läsbart sätt.
