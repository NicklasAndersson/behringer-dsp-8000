Importera från REW

0 % = ingen ändring alls, 100 % = hela REW-förslaget (störst förändring). Vid merge: 50 % tar halva felet per varv och är stabilt – hela steget kan svänga över. Merga mot importerad SysEx-fil lägger förslaget ovanpå den exporterade filens EQ i stället för reglagen – använd den när filen är exakt det som satt på enheten under mätningen.
Hur får jag ut datan ur REW? (panelen har inget REW-API ännu)

Panelen läser filen lokalt i webbläsaren – inget skickas någonstans. Formatet är det som python/rew_script.py skriver: mät sweepen i REW, starta REW:s API (Preferences → API → Start server, port 4735) och kör cd python && ./run.sh. Resultatet hamnar i python/rew_eq_suggestion.json eller python/history/suggestions/ – det är den filen du laddar upp här.

För hand duger två fält. Nycklarna är ISO-tersbandens frekvenser, gain i dB; PEQ-listan är REW:s filter med q som räknas om till bandbredd i oktaver. Enheten har 3 per kanal, så finns det fler används de 3 viktigaste: smala djupa först – en bred korrigering kan de 31 banden göra själva, en smal rumsmod kan de inte göra alls.

Andra varvet: skriv EQ:n till enheten, mät om med EQ:n aktiv, kör REW igen och importera den nya filen med läget Merga – då är förslaget residualen som läggs ovanpå det som redan står i reglagen. Samma sak som ./run.sh refine gör i Python-flödet (--refine-damping = den här andelen). Exporterade du EQ:n till fil innan mätningen? Importera filen under SysEx-fil och välj Merga mot … – då räknas residualen mot exakt det läget, oavsett vad reglagen visar nu.

SysEx-fil

Ingen fil importerad.

Exporten är en JSON-fil med de 31 bandens dB, masterfaders, de 6 PEQ-posterna och de exakta SysEx-byten (21 = GEQ, 22 = PEQ) som panelen skulle skicka – läsbar och diffbar, inte enhetens binära dump. Importen tar den filen tillbaka, och även en riktig .syx-minnesdump (t.ex. från run.sh grab eller säkerhetskopian från "Nolla alla program") – då fylls även programlistan. Inget skrivs till enheten vid import; tryck "Skriv GEQ + PEQ" när du vill det.

Program (minnesplatser 1–100)

Listan fylls med programnamnen ur "Hämta från enheten" – välj en plats så laddas dess GEQ, PEQ och namn in i reglagen ovan (kurvan "enheten" visar då den platsen). "Byt till på enheten" skickar Program Change – plats n = Program Change n−1, precis som enhetens display räknar.
"Skriv till platsen" (SysEx 23) är avkodat ur EQ-Design men ännu inte verifierat mot hårdvara – det skriver över programmet direkt. Hämta först, och hämta igen efteråt för att se att rätt plats ändrades. Arbetsbufferten (plats 0) skrivs med "Skriv GEQ + PEQ" i stället.
"Nolla platsen" skriver 104 nollbyte till valda platsen – exakt vad enheten själv har i en oanvänd plats (tomt namn, 0 dB, inga filter). "Nolla alla program" gör samma sak med alla 100, ~50 ms isär. Båda frågar först, och massraderingen laddar ner den hämtade dumpen som .syx innan den skriver – den filen är enda vägen tillbaka (./run.sh push dumpen.syx, med RCV MEMORY DUMP-knappen).

Parametriska filter (SysEx 22)

Skrivs direkt till arbetsbufferten, samma knapp som GEQ. Bandbredd i oktaver (enheten: 1/60–120/60 okt), gain +16…−48 dB i 0,5 dB-steg. Gain 0 = filtret stängs av. De 3 filtren per kanal delas med Feedback Destroyer – ställ FB-D på OFF, annars flyttar den filtren själv.

Går inte via MIDI: delay, gate, limiter, feedback destroyer, Auto-Q, stereolink. Ställ dem på enheten. (Programsparande: se panelen längst ner – otestad väg.)
"Hämta från enheten" läser hela minnesdumpen (12 kB, tar ~5 s) och fyller reglagen + kolumnen "På enheten". Kräver att enhetens EXCL SND/RCV står på ON och att båda MIDI-kablarna sitter i.
GEQ-kanal Endast L/R: SysEx 21 skriver alltid båda kanalerna, så den andra kanalen får det som senast hämtades från enheten – 0 dB om inget hämtats. Hämta först om du bara vill röra en kanal.
Det akustiska resultatet verifieras med en REW-sweep.
